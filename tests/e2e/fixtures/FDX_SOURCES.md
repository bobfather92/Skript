# FDX compatibility fixtures

`real-final-draft-v5.fdx` and `real-fade-in.fdx` are copied from the
MIT-licensed `wildwinter/screenplay-tools` interoperability test corpus:

https://github.com/wildwinter/screenplay-tools

- `real-final-draft-v5.fdx`: generated by Final Draft, FDX version 5.
- `real-fade-in.fdx`: generated by Fade In using the same screenplay.
- `fdx-advanced-conformance.fdx`: Skript conformance fixture covering dual
  dialogue, styled runs, revisions, page starts, scene metadata and notes.

The upstream copyright and MIT license are retained in the repository source
and apply to the copied interoperability fixtures.
