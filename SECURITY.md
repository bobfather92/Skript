# Security Policy

## Supported versions

Security fixes are provided for the current Skript 1.0 release line. Users should install the newest signed build available from the GitHub Releases page.

## Reporting a vulnerability

Please use GitHub's private vulnerability reporting feature for this repository. Do not publish vulnerability details, private scripts, recovery data, access tokens or personal information in a public issue.

If private reporting is unavailable, open a public issue requesting a private contact channel without including exploit details or sensitive data.

Public release installers must be Authenticode-signed and timestamped. Users should verify the Windows publisher before installation and should never be instructed to disable antivirus protection.
