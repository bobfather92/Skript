SKRIPT 1.0.0.4 WINDOWS INSTALLER

Double-click Skript-Setup-1.0.0.4.exe and choose Install.

The installer places Skript in:
  %LOCALAPPDATA%\Programs\Skript

It creates a Start Menu shortcut and can create a desktop shortcut. Skript can
be removed from Windows Settings > Apps > Installed apps, or by running
"Uninstall Skript.exe" from the installation folder.

This is a per-user installation and normally does not require administrator
permission. Official public installers are digitally signed and timestamped.
If Windows reports Unknown Publisher, do not continue; download the installer
again from the official GitHub Releases page.

The installer automatically verifies Windows, a supported browser, local
service access, installation permissions, disk space and all bundled runtime
components. Python, PDF import and Word export engines are included; users do
not need to install plugins separately.

Release status: Official Release. See RELEASE_NOTES_1.0.0.4.md.
